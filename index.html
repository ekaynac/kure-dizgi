Küre Dizgi

A. Tolga Suyolcuğlu’nun Melissa Önermesi şiirinin dizgisi için geliştirilen araçlar.

Şiiri bir küre üzerinde düzenleyin; kitap için ölçülü baskı projeksiyonları hazırlayın. Bu bağımsız pakette gerçek şiir veya kitap belgeleri değil, araçlar ve tarafsız örnekler bulunur.

Şiir editörüZengin metin, 3B küre, yaprak açılımı, JSON / SVG / PNG. Kitap projeksiyonuA / B eğrilikleri; 10,5 pt / 13 pt hedefi, 20 mm sınır ölçümü.

GitHub kaynak kodu · Kendi araç kodumuz MIT lisanslıdır; şiir ve üçüncü taraf bileşenler ayrı haklara tabidir. Yüklediğiniz şiir tarayıcıda işlenir; uygulama metninizi sunucuya göndermez.

Belgeler

  • Başlangıç ve bütün belge bağlantıları
  • Editör ve JSON yedekleri
  • Punto, satır arası ve projeksiyon bedeli
  • PDF / IDML üretimi
  • Özel arşiv, haklar ve barındırma açıklaması
  • Önceki GitHub yayını araştırması
  • Üçüncü taraf lisansları

Canlı araçlar doğrudan bu sitede çalışır. Çevrimdışı kullanım için kaynak paketini indirip index.html dosyasını açabilirsiniz. Yerel kopyadan fontları gömülü kitap SVG’si indirmek için bu klasörde python -m http.server 8000 --bind 127.0.0.1 çalıştırın; http://127.0.0.1:8000/ adresini açın. Ayrıntılar README’de.
